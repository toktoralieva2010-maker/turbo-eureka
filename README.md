# turbo-eureka
14-летний Рэнтон мечтает о приключениях. Его жизнь меняется, когда в гараж врезается гигантский робот Nirvash с загадочной девушкой Эврикой. Рэнтон вступает в команду «Гекко-Го», влюбляется в Эврику и узнает, что она — ключ к спасению мира. Главные темы: Взросление, первая любовь, понимание между разными расами и музыкальная культура.
